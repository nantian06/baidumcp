# 文档索引

仓库文档以根目录 [README.md](../README.md) 作为项目介绍与用户快速开始入口；本目录补充架构、权限边界和维护记录。实现细节以 `src/baidumcp/` 当前代码为准，百度开放平台和官方 MCP 的外部行为可能变化。

| 文档 | 适用读者 | 内容 |
|---|---|---|
| [逻辑设计与权限边界](design.md) | 使用者、集成者、贡献者 | 模块职责、授权与传输流程、配置/状态位置、安全边界和已知限制 |
| [维护日志](changelog.md) | 仓库维护者 | 按时间记录对项目文档和维护说明的变更；不替代 Git 历史或版本发布说明 |

## 更新约定

- 项目定位、安装、快速开始和常用命令以根目录 README 为准；架构和风险说明在 `design.md` 维护，避免多处重复描述同一规则。
- 修改文档时同步更新本日志，记录时间、类型、内容与影响；代码发布版本仍以项目版本和 Git 标签为准。
- 文档说明与代码行为不一致时，以当前实现为准，并通过修订文档消除差异；对外部服务行为注明其外部依赖属性。
